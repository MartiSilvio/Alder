# Changelog

## 1.0.0 - 2026-05-03

Initial release of Alder: an embeddable C# runtime engine with parser, binder, interpreter, opt-in compiled backend, async execution, Dynamic LINQ over `IEnumerable<T>`, `IQueryable<T>`, and `IAsyncEnumerable<T>`, LINQ expression-tree export, host-controlled sandbox, execution constraints, and NativeAOT generated dispatch.
